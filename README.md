# Best MEP Pvt Ltd — Modern Luxury Website

A luxury, high-performance, responsive corporate website built for **Best MEP Private Limited** — Mechanical, Electrical, Plumbing, ELV, BMS, Fire Fighting & Civil Contractors.

## ✨ Features

- **Luxury Aesthetics & Color Scheme**: Modern obsidian & midnight palette with champagne gold accents, high-contrast typography, and frosted glass elements.
- **Ultra-HD Hero Banner**: Dynamic animated background banner featuring real industrial MEP installations and power substation infrastructure.
- **Pure Web Engineering**: 100% Vanilla HTML5, CSS3, and JavaScript — Zero Python, zero complex server dependencies.
- **Interactive Animations**:
  - Stats number counter animations (IntersectionObserver)
  - Staggered scroll-reveal entrance animations
  - Interactive service filtering tabs (HVAC, Automation, Electrical, Civil)
  - Expandable detailed scope accordions
  - Fullscreen HD image lightbox modal for site photographs
  - Floating back-to-top button with circular SVG scroll progress ring
- **Fully Responsive**: Mobile-first fluid design with animated hamburger drawer and touch-friendly controls.

## 🚀 Getting Started

Simply open `index.html` in any web browser, or run locally:

```bash
npm start
```

This starts a local development server at `http://localhost:3000`.
